# Style Fidelity QA

## Style Goal

Verify the finished piece still **is** observational-info-short — a credible human observation with conversational clarity — not a technically passable clip that drifted into ad, news, trailer, or corporate genres. This dimension covers **Style Fidelity QA only**, not technical deliverable QA.

## Inherit from Common Craft

Consult `video-workflow/knowledge/editing-craft/aesthetic-qa.md` for rule hierarchy:

1. Safety and factual integrity — non-negotiable
2. Frozen assets and content authority
3. **Style fidelity** — this file
4. Owner review — subjective final acceptance

Technical checks (black frames, file existence, codec, timeline gaps, render path) belong to Universal / Final Artifact QA layers — **out of scope here**.

## Style Defaults

Evaluate holistically after viewing / listening as audience:

| Check axis | Pass condition (Style) |
|------------|------------------------|
| Genre identity | Reads as observational / light knowledge short — peer voice |
| Authenticity | Human observation credible; not performed or sterile |
| Restraint | Transitions, effects, captions, music within Style ceilings |
| Semantic fit | Visuals support narration roles — not generic montage |
| Rhythm feel | Conversational brisk — not anxious news or slow cinema |
| Sound grammar | Voice wins; original sound and breath present where expected |
| Typography | Readable, restrained — not performance subtitles |
| Color / finish | Natural coherent — not ad glossy or faux cinematic |

Each item: **PASS** | **FAIL** | **N/A** (with reason).

Overall Style Fidelity: **PASS** only if no blocking FAIL on genre-critical axes.

## Prefer When

- Review full piece start-to-end before scoring — checkbox item isolation misses OBS-STYLE-19 pattern
- Map failures to dimension reference for repair (`01`–`07`)
- Fail closed on genre drift even if individual shots look attractive
- Note intentional Brief overrides separately — not Style FAIL
- Use taste failure mode vocabulary from `07-taste.md` in failure descriptions

## Allow When

- N/A with reason for Brief-disabled feature (e.g., music `OWNER_DISABLED`)
- Single beat local Owner intent exception documented — do not FAIL whole piece if isolated and authorized
- Creative Direction refinement within bounds — assess against axes, not personal taste alone

## Avoid When

- Treating timeline-only inspection as Style fidelity PASS
- Passing because no single rule triggered while overall feel is wrong
- Conflating technical gap/black frame defects with this checklist — route to technical QA
- Demanding Style FAIL for format adaptation choices (9:16 crop) when identity intact

## Prohibit

- Using this file as sole QA gate for technical deliverable acceptance
- Fake PASS when piece clearly reads as travel ad, news bulletin, trailer, or corporate promo
- FAILing intentional caption-free breath beats as subtitle defects
- FAILing absent music when Owner disabled music

## Exceptions

- Brief explicitly requests genre hybrid — document `BRIEF_OVERRIDE`; evaluate against stated hybrid target, not default Style
- Automation cannot assess subjective genre feel — flag `STYLE_FIDELITY_REQUIRES_OWNER_REVIEW`; do not invent PASS

## Trade-offs

| QA stance | Gain | Cost |
|-----------|------|------|
| Holistic genre read | Catches stock-slideshow drift | Less binary automation |
| Style-only scope | Clear responsibility split | Requires separate technical QA |
| Fail closed on drift | Protects Style identity | May reject polished but wrong-genre edits |
| Taste vocabulary in reports | Actionable repair routing | Longer QA notes |

## Capability Intent

Style Fidelity QA does not execute edit capabilities. It may **require evidence** from:

- `qa.final_artifact` — viewing delivered MP4, not timeline assumption
- `qa.visual.frame` — subject readability in format adaptation
- `qa.subtitle.layout` — caption width / line discipline in artifact

Absence of verified QA route → `STYLE_FIDELITY_REQUIRES_OWNER_REVIEW`, not silent PASS.

## QA Signals

### OBS-STYLE-01 — Ad-like Drift

**FAIL** if: ad posing stock dominates, aggressive zoom/push habitual, music wall-to-wall loud, promo transitions, constant keyword 花字, glossy grade, CTA energy.

### OBS-STYLE-02 — News-like Drift

**FAIL** if: anxious cutting, ticker urgency, broadcast hard voice treatment, lower-third breaking banner energy, information panic pacing.

### OBS-STYLE-03 — Cinematic / Trailer Drift

**FAIL** if: teal-orange grade identity, shallow-DoF beauty without evidence job, whip/spin/flashing transitions, trailer SFX density, dramatic angles on mundane facts.

### OBS-STYLE-04 — Corporate Drift

**FAIL** if: sterile VO-only world, template corporate lower thirds, risk-averse emptiness, brand-safe stock people smiling without observation point.

### OBS-STYLE-05 — Authenticity Loss

**FAIL** if: no original sound or breath where Blueprint planned; environment feels fake; uncorrected obvious slow motion; voice feels performed announcer not peer.

### OBS-STYLE-06 — Anxious Cutting

**FAIL** if: cuts feel unmotivated rapid fire; semantic units broken for energy alone; hook chaotic without orienting information.

### OBS-STYLE-07 — Subtitles Overpowering

**FAIL** if: decoration exceeds primary caption role; text dominates subject persistently; meme or news typography; all-line emphasis.

### OBS-STYLE-08 — Music Over Voice

**FAIL** if: music masks consonants or proper nouns; emotional swells over unearned narration; bed competes with observational calm.

### OBS-STYLE-09 — Insufficient Original Sound / Breath

**FAIL** if: entire piece sterile voice-over bed; planned **BREATH** / **ORIGINAL_SOUND** beats flattened; ambience value axis absent.

### OBS-STYLE-10 — Generic Stock Montage

**FAIL** if: unrelated beautiful clips sequence; weak semantic alignment; filename-driven selection visible; "slow stock + voiceover" fakery overall (even when isolated technical checks pass).

### OBS-STYLE-11 — Observation Identity

**PASS** only if: core feeling remains "friend telling you something interesting they noticed" — conversational, clear, lightly engaging, credible.

## Reference Cases

**RC-VIS-001 failure pattern:** Payment beat uses aggressive push-in + heavy grade → **OBS-STYLE-03** cinematic drift + **OBS-STYLE-01** ad-like emphasis; repair via `02-visual-language.md` + `06-color-look-effects.md`.

**Stock slideshow PASS trap:** All clips sharp and timed, but unrelated to narration claims → **OBS-STYLE-10** FAIL despite attractive visuals.

**Breath beat false FAIL:** Intentional 4s caption-free market ambience → **N/A** for subtitle overpowering if Blueprint documented `caption-free breath`.

**Music disabled production:** No music bed → **OBS-STYLE-08** N/A; verify `OWNER_DISABLED` not drift.

**Sunday closure piece:** Hard contrast aligned with narration, natural motion, ducked music at ambient church bell original sound → **OBS-STYLE-11** PASS exemplar.
