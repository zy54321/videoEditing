# Editing Craft Knowledge Layer

## Purpose

This directory holds **Common Craft Knowledge** — professional film and video editing principles shared across all L2 Styles.

It is **not** a Skill. It is **not** invoked as a production entry point.

---

## What This Layer Answers

> “影视剪辑一般有哪些专业原则？”

Examples: shot size meaning, cut motivation, sound hierarchy, subtitle readability physics, color correction order.

---

## What L2 Style Answers

> “这种具体风格如何选择、组合、或打破这些原则？”

Example:

- **Craft:** Close-up can intensify detail and emotion.
- **Style (`observational-info-short`):** Use close-up only when evidence, contrast, or emotion truly needs it — not for generic “cinematic” feel.

---

## Authority

| Layer | Authority |
|-------|-----------|
| Common Craft | Explains professional defaults |
| L2 Style | Final aesthetic choice for a genre |
| Edit Blueprint | Beat-level plan for one production |
| L1 Capability | What is technically possible / verified |

**Craft Knowledge cannot override Style.**

Style is the final aesthetic selection layer for a chosen genre.
