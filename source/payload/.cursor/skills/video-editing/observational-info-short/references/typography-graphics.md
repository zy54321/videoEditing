# Observational Info Short — Typography & Graphics

Common craft baseline: `video-workflow/knowledge/editing-craft/typography-graphics.md`

---

## Subtitle Strategy

**Default: ON** unless Brief disables.

### Content vs Presentation

**Frozen:** facts, numbers, proper nouns, core meaning — must not change.

**Allowed:** re-segment cues, line breaks, timing, merge/split — semantics unchanged.

### Layout (9:16)

Craft contract (this Style adopts):

- target width ~**76–78%** of frame; hard ceiling **80%**
- max **2 lines**
- semantic line breaks — not character-count chop alone
- minimum readable size — do not shrink to fit

Overflow: semantic wrap → cue split.

### Visual types

| Type | Use |
|------|-----|
| Standard Caption | default — high readability |
| Keyword Emphasis | 1–3 key elements per section |
| Title / Section | hook or mini-chapter only |

Prohibit all-lines 花字.

`subtitle.visual_style` UNKNOWN does not block **functional** captions.

### Final subtitle QA

Timeline subtitle count ≠ MP4 correctness. Verify rendered artifact (`qa.md` OBS-QA-FINAL-RENDER).

---

## Graphics Strategy

Graphics only when understanding improves.

**Suitable:** place names, time, numbers, keywords, simple callouts  
**Not suitable:** decorative UI filler

Default: **minimal** — clean, simple, brief titles / lower thirds.

---

## Caption Personality (this Style)

- restrained, readable, conversational
- not meme-style, not news ticker flash
- Creative Direction may request “more playful” within readability bounds — not a new Style
