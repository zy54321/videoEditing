## Shot Preference

| Preference | Guidance |
|------------|----------|
| Shot size | Mix wide establish + medium action; close-up only for evidence, contrast, emotion |
| Camera feeling | Observational, stable-to-light handheld; not aggressive promo angles |
| Composition | Clear subject hierarchy; readable action in 9:16 |

**Craft says:** close-up intensifies detail.  
**This Style says:** use close-up when evidence or contrast needs it — not for generic “film look.”

---

## 9:16 Framing

Short-form default: **subject first.**

Horizontal source:

- fill frame
- preserve aspect ratio
- reposition for face / hands / key object

**Prohibit:** stretch, unintended letterbox/pillarbox.

| Subject | Preserve |
|---------|----------|
| People | face, upper body, action |
| Object action | hands, payment, tools |
| City | landmark, vehicle, pedestrian relation |

If crop impossible: alternate range → alternate source → intentional layout only if Brief allows.
