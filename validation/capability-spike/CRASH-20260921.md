# Resolve Crash Record — 2026-09-21

**Stage:** V0.1 Stage 04A — DaVinci Capability Spike  
**Status:** Terminated by runtime crash  
**Project under test:** `VEW-Capability-Spike-V01` (disposable only)

---

## Summary

During automated subtitle route testing, DaVinci Resolve Studio 21.1.0.14 aborted while processing a subtitle-targeted `MediaPool.AppendToTimeline` call. The MCP returned `APPEND_TO_TIMELINE_FAILED`; Resolve then lost scripting API connectivity and crashed.

**This document records evidence only. It does not claim a single root cause.**

---

## Crash Boundary

```
CRASH_BOUNDARY =
  SRT MediaPool item
  → MediaPool.AppendToTimeline
  → subtitle-targeted append
  → Resolve abort
```

**Rule for automated production:**

> **DO NOT RETRY** `SRT → MediaPool → AppendToTimeline` in automated production workflows.
