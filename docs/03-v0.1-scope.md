## 明确 Out of Scope

以下全部属于**后续版本**，V0.1 不做：

| 类别 | 排除项 |
|------|--------|
| MCP | 第二套 DaVinci MCP、自建 MCP |
| 集成 | Astra integration |
| UI | GUI、Web UI |
| 基础设施 | Database、Skill Registry Service、Runtime Manager |
| 自动安装 | Node / Python 自动安装、Resolve 自动安装、MCP 自动安装、OFX 自动安装 |
| L2 Skills | News、Documentary、Vlog、Opinion、Tech Explainer |

## V0.1 Acceptance

在一个**新的 Cursor 工作区**中初始化 Release 后：

**输入：** 只提供一个 Production Brief + 调用 `video-production` Skill

**系统应能自动：**

1. 读取 Brief
2. 加载 `observational-info-short`
3. 使用当前已存在的 Resolve MCP
4. 分析媒体
5. 生成 Editing Plan
6. 完成剪辑
7. 完成：
   - motion normalization
   - framing
   - transitions
   - subtitles
   - background music integration
8. QA
9. Repair
10. Render
11. Closeout

**首个真实 Acceptance Case：** N02
